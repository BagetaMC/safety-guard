Quick answers about Safety Guard.
Is Safety Guard free?

Safety Guard’s website preview does not define pricing. Add your actual free or premium plan details here when they are decided.

How do I add Safety Guard to my Discord server?

Use the Add to Discord button to open the bot’s official Discord authorization link. The button needs your real OAuth invite URL before it can add the bot.

Can I configure the bot from my phone?

Yes — this page is responsive and adapts to mobile and desktop screens. Live configuration requires connecting the dashboard to the bot’s backend.

What security features does Safety Guard include?

The planned feature set includes Anti-Spam, Anti-Raid, CAPTCHA verification, ticket tools, logging and additional moderation controls. Availability depends on the bot implementation.
